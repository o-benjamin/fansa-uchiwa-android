# R8 / ProGuard（難読化・シュリンク）

- **R8 / ProGuard によるクラス保護**:
    - リリースビルドの難読化・シュリンク（R8）からクラスを保護する必要がある場合（例: Room に JSON
      で永続化されるクラス、WorkManager
      がクラス名で参照する`Worker`など、クラス名がコード外から参照されるもの）は、`app/proguard-rules.pro`
      に個別のクラス名やパッケージ名を書かないでください。
    - 代わりに、保護対象のクラス自身に `androidx.annotation.Keep` を付与してください。リネームやパッケージ移動に追従でき、保護の意図もクラス定義の場所で明示できます。
    - `@Keep` はサブクラスに継承されないため、sealed
      interface/classの各サブクラスなど、保護が必要な型にはそれぞれ個別に付与してください。
    - `app/proguard-rules.pro` には、特定クラスに依存しない汎用的なルール（属性の保持設定など）のみを記述してください。
