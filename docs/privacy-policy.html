プライバシーポリシー

このプライバシーポリシーは、Kenshin Sasaki（以下「提供者」）が提供するモバイルデバイス向けの基本無料アプリ「ファンサうちわAndroid」（以下「本アプリ」）に適用されます。本サービスは現状有姿で提供されます。

情報の収集と利用

本アプリは、アプリの品質向上、利便性の改善、および広告配信を目的として、以下の情報を自動的に収集します。これらの情報は個人を特定するものではありません。

  • デバイスのIPアドレスおよび端末識別子（Android広告ID、アプリセットID）
  • アプリ内の操作ログ（タップ、画面遷移、共有先に選んだアプリ、動画広告の視聴状況等）
  • アプリのパフォーマンス情報および診断データ（クラッシュログ、スタックトレース、メモリ使用状況等）
  • デバイス情報（モデル、OSバージョン、言語設定等）
本アプリが利用する第三者サービス
本アプリでは、以下の第三者サービスを利用しています。このうち、目的に「AI素材」とあるサービスは、今後のアップデートで提供する予定のAI素材の機能（下記）で利用するもので、機能の提供を始めるまでは利用しません。
・Google AdMob：広告の最適化および配信のため。
・Unity Ads：広告の配信のため（Google AdMob のメディエーション経由）。
・Liftoff Monetize：広告の配信のため（Google AdMob のメディエーション経由）。
・Google Analytics for Firebase：アプリの利用状況分析による機能改善のため。
・Firebase Crashlytics：クラッシュ発生時の原因究明とアプリの安定性向上のため。
・Firebase Remote Config：アプリの設定値（おすすめ材料のリンク、今日のお題など）を配信するため。
・Firebase Authentication：AI素材の機能で、無料の1回と回数券（AI素材を作れる回数を、アプリ内で購入するもの）を利用者ごとに数えるため（匿名の利用者IDのみ）。
・Firebase App Check（Google Play Integrity）：AI素材の機能でサーバーを呼び出すとき、ストアから入れた本アプリからの呼び出しかを確かめ、不正利用を防ぐため。
・Cloud Functions for Firebase・Cloud Firestore：AI素材の作成の受け付け、回数・購入・報告の記録のため。
・Google Gemini API：AI素材の機能で、入力した文章と元画像が作ってよい内容かの自動の確認と、素材の画像の作成のため。
・Google Play 請求サービス：AI素材の回数券の購入のため。
・Discord：AI素材の報告が届いたことを提供者が知るため（報告の理由と AI のモデル名のみ）。
・Amazonアソシエイト・プログラム：うちわの材料を紹介するリンクを表示し、リンク先での購入を計測するため（リンク先では Amazon が情報を取得します）。
Amazonのアソシエイトとして、ファンサうちわは適格販売により収入を得ています。

AI素材の機能で送信・保存する情報

この項は、今後のアップデートで提供する予定の機能についての説明です。機能の提供を始めるまで、以下の情報を送信・保存することはありません。

文章（元画像を添えることもできます）からうちわに置く素材を作る「AIで素材を作る」の機能（以下「AI素材の機能」）を使うときに限り、以下の情報を送信・保存します。この機能を使わなければ、これらの情報は送信されません。

  • 匿名の利用者ID： AI素材の機能を初めて使うときに、Firebase Authentication でランダムな利用者IDを作ります。お客様がログインの操作をすることはなく、アプリが自動で行います。お名前やメールアドレスなどはお預かりしません。利用者IDを作るとき、不正防止のためにIPアドレスが Firebase に記録されます。
  • アプリの正当性の確認： 素材を作る、回数券を購入する、素材を報告するときに、ストアから入れた本アプリからの呼び出しかを確かめて不正利用を防ぐため、Firebase App Check を通じて Google Play Integrity の確認結果（トークン）を送信します。
  • 入力した文章と元画像： 入力した文章と、選んだ場合は元画像1枚を、素材を作るために、提供者のサーバー（Cloud Functions for Firebase）を経由して Google の Gemini API に送信します（作ってよい内容かを AI が自動で確かめたうえで作ります）。提供者のサーバーには、文章と画像を保存しません。提供者は Gemini API を有料の契約で利用しており（無料の1回で作るときも同じです）、Google の利用規約により、送信した内容は Google の製品の改善（AI の学習を含む）には使われません。ただし Google は、不正利用の検出などのために一定期間記録することがあります。元画像に人の顔が写っていないかの確認と、素材の背景の切り抜きは、端末内で行います。
  • 回数の記録： 利用者IDごとに、無料の1回を使ったかどうかと、回数券の残りの回数・期限を Cloud Firestore に保存します。
  • 購入の記録： 回数券を購入したとき、Google Play の注文番号・購入した商品・購入日時・回数券の期限を、利用者IDとあわせて保存します。お支払い方法（カード番号など）は Google Play が取り扱い、提供者は受け取りません。返金された購入は、Google Play から返金の情報を受け取り、回数券を取り消します。
  • 報告の内容： 作った素材を報告ボタンで報告したとき、確認画面でお知らせしたうえで、入力した文章・報告の理由（一覧から選んだもの）・素材を作った AI のモデル名を、利用者IDとあわせて保存します（画像は送信しません）。報告の内容は、問題のある素材を防ぐ対策に使います。1日に送れる報告の数を抑えるため、利用者IDごとにその日の報告の数も保存します。報告が届いたことを提供者が知るため、報告の理由とモデル名だけを Discord で提供者に知らせます（文章と利用者IDは送りません）。

データのローカル保存と写真へのアクセスについて

本アプリは、ユーザーのプライバシーを最優先に設計されています。うちわのデータと写真は、以下のとおり端末内で扱います（AI素材の機能で選んだ元画像と、下記の端末のバックアップを除きます）。

  • うちわデータの保存： 本アプリで作成・編集したうちわのデータ（テキスト、配置、設定等）は、お客様の端末内に保存されます。提供者や第三者のサーバーに送信されることはありません（下記の端末のバックアップを除きます）。
  • 写真へのアクセス： うちわに画像を挿入する際、端末内の写真ライブラリにアクセスします。うちわに挿入する画像が外部サーバーにアップロードされたり（下記の端末のバックアップを除きます）、提供者がそれらを収集したりすることはありません。背景の切り抜きなどの画像処理は端末内で行われます。ただし、AI素材の機能で元画像を選んだときに限り、その1枚を素材の作成のために送信します（上記「AI素材の機能で送信・保存する情報」）。
  • 端末のバックアップ： Android のバックアップ機能をオンにしている場合、本アプリが端末内に保存したデータ（うちわのデータ、挿入した画像、AI素材の利用者IDなど）は、お客様の Google アカウントのバックアップに含まれることがあり、機種変更や再インストールのときに復元されます。バックアップは Google が管理し、提供者はその中身を見ることはできません。バックアップの設定は、端末の設定アプリで変えられます。

第三者への提供

本アプリは、上記の目的のために、上記の第三者サービスへデータを送信します。AI素材の機能で入力した文章と選んだ元画像は、素材の作成のために Google（Gemini API）へ送信されます。これらのサービスでの処理は、日本国外のサーバーで行われることがあります。本アプリが利用する第三者サービスのプライバシーポリシーについては、以下のリンクからご確認ください。

  • Google（Google Play 開発者サービス・Gemini API・Google Play 請求サービス）
  • AdMob
  • Unity Ads
  • Liftoff Monetize
  • Firebase (Analytics / Crashlytics / Remote Config / Authentication / App Check / Cloud Functions / Cloud Firestore)
  • Gemini API 利用規約
  • Discord
  • Amazon（プライバシー通知）

オプトアウト権

本アプリをアンインストールすることで、アプリによるすべての情報収集を停止できます。モバイルデバイスの標準的なアンインストール手順をご利用ください。アンインストールすると端末内の利用者IDは消えます（端末のバックアップから復元した場合は、同じ利用者IDに戻ります）。サーバーに保存した利用者ID・回数・購入・報告の記録は残ります（削除は次の項をご覧ください）。

データの保存期間と削除

匿名の利用者IDと、AI素材の機能の回数・購入の記録は、期限を決めずに保存し、削除のご依頼があれば削除します（ご依頼で削除できる記録と頼み方は、次の段落のとおりです）。報告の内容は180日後に、1日ごとの報告の数は2日後に、自動で削除します。入力した文章と元画像は、提供者のサーバーには残りません（Google 側の記録は上記「AI素材の機能で送信・保存する情報」のとおりです）。サーバーの動作の記録（ログ）には、利用者IDや注文番号が残ることがあります（文章と画像は書きません）。ログは30日後に自動で削除され、個別には削除しません。

削除をご希望の場合は、下記のお問い合わせ先までご連絡ください。回数券を購入した方（プロモーションコードで受け取った方を含みます）は、Google Play の注文番号（「GPA.」で始まる番号。Google Play の購入履歴や領収書のメールに記載されています）をお知らせいただくと、その購入と、同じ利用者IDの記録を探して削除します。プロモーションコードで受け取ったときなど注文番号がない場合は、受け取った日時をお知らせください。削除すると、残りの回数券は使えなくなります。報告をした方は、報告した日と文章をお知らせいただくと、その報告と、同じ利用者IDの記録を削除します。どちらにも当たらない方の記録は、匿名の利用者IDと無料の1回を使ったかどうかだけで、お名前などとは結びついていないため、提供者の側でどなたの記録かを特定できず、個別に削除することはできません。
