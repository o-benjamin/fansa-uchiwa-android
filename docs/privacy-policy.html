プライバシーポリシー

このプライバシーポリシーは、Kenshin Sasaki（以下「提供者」）が提供するモバイルデバイス向けの基本無料アプリ「ファンサうちわAndroid」（以下「本アプリ」）に適用されます。本サービスは現状有姿で提供されます。

情報の収集と利用

本アプリは、アプリの品質向上、利便性の改善、および広告配信を目的として、以下の情報を自動的に収集します。これらの情報は個人を特定するものではありません。

  • デバイスのIPアドレスおよび端末識別子（Android広告ID、アプリセットID）
  • アプリ内の操作ログ（タップ、画面遷移、共有先に選んだアプリ、動画広告の視聴状況等）
  • アプリのパフォーマンス情報および診断データ（クラッシュログ、スタックトレース、メモリ使用状況等）
  • デバイス情報（モデル、OSバージョン、言語設定等）
広告配信、分析、および品質管理について
本アプリでは、以下の第三者サービスを利用しています。
・Google AdMob：広告の最適化および配信のため。
・Unity Ads：広告の配信のため（Google AdMob のメディエーション経由）。
・Liftoff Monetize：広告の配信のため（Google AdMob のメディエーション経由）。
・Google Analytics for Firebase：アプリの利用状況分析による機能改善のため。
・Firebase Crashlytics：クラッシュ発生時の原因究明とアプリの安定性向上のため。
・Firebase Remote Config：アプリの設定値（おすすめ材料のリンク、今日のお題など）を配信するため。
・Firebase Authentication：AI素材の機能で、無料の回数と回数券を利用者ごとに数えるため（匿名の利用者 ID のみ）。
・Firebase App Check（Google Play Integrity）：AI素材のサーバーへの呼び出しが、ストアから入れた本アプリからのものかを確かめ、不正利用を防ぐため。
・Cloud Functions for Firebase・Cloud Firestore：AI素材の作成の受け付け、回数・購入・報告の記録のため。
・Google Gemini API：AI素材の機能で、入力された文章と元画像の審査、および素材の画像の作成のため。
・Google Play 請求サービス：AI素材の回数券の購入のため。
・Amazonアソシエイト・プログラム：うちわの材料を紹介するリンクを表示し、リンク先での購入を計測するため（リンク先では Amazon が情報を取得します）。
Amazonのアソシエイトとして、ファンサうちわは適格販売により収入を得ています。

AI素材の機能で送信・保存する情報

文章（と任意の元画像）からうちわに置く素材を作る「AI素材」の機能を使うときに限り、以下の情報を送信・保存します。この機能を使わなければ、これらの情報は送信されません。

  • 匿名の利用者 ID： AI素材の機能を初めて使うときに、Firebase Authentication でランダムな利用者 ID を作ります。お名前やメールアドレスなどはお預かりしません。ログインの際、不正防止のために IP アドレスが Firebase に記録されます。
  • アプリの正当性の確認： AI素材のサーバーを呼び出すとき、Firebase App Check を通じて Google Play Integrity の確認結果（トークン）を送信します。
  • 入力した文章と元画像： 入力した文章と、選んだ場合は元画像1枚を、素材の作成のために提供者のサーバー（Cloud Functions for Firebase）を経由して Google の Gemini API に送信します。提供者のサーバーには、文章と画像を保存しません。Gemini API は有料プランで利用しており、Google の利用規約により、送信した内容は Google の製品の改善（AI の学習を含む）には使われません。ただし Google は、不正利用の検出などのために一定期間記録することがあります。元画像に人の顔が写っていないかの確認と、素材の背景の切り抜きは、端末内で行います。
  • 回数の記録： 利用者 ID ごとに、無料の1回を使ったかどうかと、回数券の残りの回数・期限を Cloud Firestore に保存します。
  • 購入の記録： 回数券を購入したとき、Google Play の注文番号・購入した商品・購入日時・回数券の期限を、利用者 ID とあわせて保存します。お支払い方法（カード番号など）は Google Play が取り扱い、提供者は受け取りません。返金された購入は、Google Play から返金の情報を受け取り、回数券を取り消します。
  • 報告の内容： 作った素材を報告ボタンで報告したとき、確認画面でお知らせしたうえで、頼んだ文章・選んだ理由・素材を作った AI のモデル名を、利用者 ID とあわせて保存します（画像は送信しません）。報告の内容は、問題のある素材を防ぐ対策に使い、180日後に自動で削除します。

データのローカル保存と写真へのアクセスについて

本アプリは、ユーザーのプライバシーを最優先に設計されています。うちわのデータと写真は、以下のとおり端末内で扱います。

  • うちわデータの保存： 本アプリで作成・編集したうちわのデータ（テキスト、配置、設定等）は、すべてお客様の端末内にのみローカル保存されます。提供者や第三者のサーバーに送信されることは一切ありません。
  • 写真へのアクセス： うちわに画像を挿入する際、端末内の写真ライブラリにアクセスします。うちわに挿入する画像が外部サーバーにアップロードされたり、提供者がそれらを収集したりすることはありません。背景の切り抜きなどの画像処理は端末内で行われます。ただし、AI素材の機能で元画像を選んだときに限り、その1枚を素材の作成のために送信します（上記「AI素材の機能で送信・保存する情報」）。

第三者への提供

本アプリは、上記の目的のために、上記の第三者サービスへデータを送信します。AI素材の機能で入力した文章と選んだ元画像は、素材の作成のために Google（Gemini API）へ送信されます。本アプリが利用する第三者サービスのプライバシーポリシーについては、以下のリンクからご確認ください。

  • Google Play Services
  • AdMob
  • Unity Ads
  • Liftoff Monetize
  • Firebase (Analytics / Crashlytics / Remote Config / Authentication / App Check / Cloud Functions / Cloud Firestore)
  • Gemini API 利用規約
  • Amazon（プライバシー通知）

オプトアウト権

本アプリをアンインストールすることで、アプリによるすべての情報収集を停止できます。モバイルデバイスの標準的なアンインストール手順をご利用ください。アンインストールすると端末内の利用者 ID は消えますが、サーバーに保存した回数・購入・報告の記録は残ります（削除は次の項をご覧ください）。

データの保存期間と削除

AI素材の機能の回数と購入の記録は、削除のご依頼があるまで保存します。報告の内容は、180日後に自動で削除します。

削除をご希望の場合は、下記のお問い合わせ先までご連絡ください。回数券を購入した方は、Google Play の注文番号（「GPA.」で始まる番号。Google Play の購入履歴や領収書のメールに記載されています）をお知らせいただくと、該当する記録を探して削除します。削除すると、残りの回数券は使えなくなります。報告の削除をご希望の場合は、報告した日と文章をお知らせください。回数券を購入していない方の記録は、匿名の利用者 ID と無料の1回を使ったかどうかだけで、お名前などとは結びついていません。
